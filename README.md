# 🚀 Unified Monitoring Dashboard

A web-based dashboard that simulates and monitors multiple systems (VMs/containers) in real time. It provides a centralized interface to track system performance, assign health status, and generate alerts.

---

## 📌 Features

- 🖥️ Simulates multiple systems (VMs/containers)
- 📊 Real-time CPU, Memory, and Disk usage
- ❤️ Health status (Healthy, Warning, Critical)
- 🔄 Auto-refresh every 2 seconds
- 🚨 Basic alert system
- 📈 Centralized monitoring dashboard

---

## 🛠️ Tech Stack

**Frontend**
- React.js

**Backend**
- Node.js
- Express.js
